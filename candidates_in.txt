# Candidate universe for Amazon India (amazon.in) — the default marketplace.
#
#     python3 amazon_selector/shortlist.py \
#         --keywords-file amazon_selector/candidates_in.txt
#
# WHAT THIS IS: keywords to RANK. An input, not a result, and not a
# recommendation. Nothing here has been validated against demand data —
# validating it is what the pipeline is for.
#
# WHY IT IS NOT THE US LIST: the catalogues genuinely differ. Ayurvedic and
# hair-oil categories are mainstream here and niche there; tallow balm and
# snail mucin are the reverse. Price bands, pack sizes and the B2B buyer all
# differ too, which is why the gates are denominated in INR (see MARKETS in
# shortlist.py) rather than converted at run time. candidates_us.txt is kept
# for the US marketplace.
#
# B2B NOTE: Amazon Business India sells largely to GST-registered buyers —
# offices, clinics, schools, small manufacturers, kirana and retail resellers.
# The office/industrial block below exists so the B2B profile has stock to
# work with; consumer-only categories will mostly fail the B2B order-value
# floor, and that is the gate doing its job rather than a bug.
#
# COST: the trend call is one request per keyword per profile. This file with
# --profile both is ~230 requests before any competition call fires. Start
# with a slice:
#
#     head -40 candidates_in.txt > slice.txt
#
# PROVENANCE: general knowledge of the Indian e-commerce catalogue, chosen to
# span consumer-only, B2B-only and dual-channel products. Not derived from
# demand data. Seed it from Amazon Product Opportunity Explorer instead if you
# have a Professional seller account — that is real Amazon data and it answers
# "what is rising" directly rather than by inference.
